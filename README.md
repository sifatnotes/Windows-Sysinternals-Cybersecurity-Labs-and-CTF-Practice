## Introduction

Windows Sysinternals utilities help administrators and security practitioners investigate processes, services, network activity, logged-on sessions, and system startup behavior.

These hands-on cybersecurity labs offer a structured way to explore tools and concepts relevant to Windows administration, defensive security, system monitoring, and incident response.

## Categories

- **Process analysis:** PsList, PsKill, Process Explorer, Process Monitor, and process suspension.
- **Windows services:** PsService and service investigation.
- **Remote administration:** PsExec and PsFile.
- **System intelligence:** PsInfo and PsLoggedOn.
- **Network monitoring:** TCPView.
- **Startup investigation:** Autoruns.

These categories support learning across Windows administration, blue-team operations, digital investigation, and security troubleshooting.

## Learning Path

1. **Explore system information:** Start with PsInfo and learn how system details support investigations.
2. **Investigate processes:** Use PsList and Process Explorer to understand running processes.
3. **Observe system activity:** Explore Process Monitor and practice identifying relevant events.
4. **Review services and sessions:** Study PsService and PsLoggedOn.
5. **Understand network activity:** Use TCPView to inspect active connections.
6. **Examine startup behavior:** Explore Autoruns to understand programs configured to run automatically.
7. **Study remote administration:** Finish with PsFile and PsExec in an authorized lab environment.

## How to Use the Labs
